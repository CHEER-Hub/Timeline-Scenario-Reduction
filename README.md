
# Scenario Selection for Long Term Hurricane Loss Timelines

This repository contains the full implementation of a scenario selection framework for reducing large ensembles of long term hurricane loss timelines. All code, documentation, and figure generation are contained in a single Jupyter notebook for transparency and reproducibility.

The repository is intended to support the analyses and figures presented in the associated manuscript.

## Repository Contents

```text
├── scenario_selection_gurobi.ipynb   # Complete implementation and documentation
├── Data/
│   ├── Inputs/                       # Input data used by the notebook
│   └── Outputs/                      # Model outputs generated by the notebook
├── Figures/                          # Figures generated for the manuscript
└── README.md
````

## Overview

The notebook implements a scenario selection optimization framework designed to reduce a large ensemble of long term hurricane loss timelines while preserving key statistical and temporal properties. The reduced scenario sets are evaluated against the full ensemble using multiple diagnostics related to event occurrence, hazard intensity, and loss behavior.

All preprocessing, optimization, evaluation, and figure generation steps are documented and executed within the same notebook to ensure full traceability of results.

## Methods Summary

The analysis proceeds in four main stages.

1. Load and preprocess long term hurricane scenario data from the full ensemble
2. Formulate and solve a mixed integer optimization problem for scenario selection using Gurobi
3. Evaluate the statistical fidelity of reduced scenario sets relative to the full ensemble
4. Generate figures and summary statistics used in the manuscript

The optimization selects a subset of scenarios and assigns unequal weights in order to best match reference statistics computed from the full ensemble.

## Main Notebook

### scenario_selection_gurobi.ipynb

This notebook contains:

• Data loading and preprocessing
• Optimization model formulation and solution using Gurobi
• Sensitivity analyses across different reduced set sizes and random seeds
• All figure generation used in the paper
• Inline documentation explaining each step of the workflow

Running the notebook from top to bottom reproduces all results presented in the manuscript.

## Running the Code

### Requirements

The analysis was developed and tested using Python 3.x.
The optimization relies on Gurobi and requires a valid Gurobi license.

### Execution

Open and run the notebook:

```bash
jupyter notebook scenario_selection_gurobi.ipynb
```

Execute all cells sequentially to reproduce the full analysis and figures.

## Reproducibility

All random seeds used in the analysis are explicitly set within the notebook. Running the notebook with the same inputs and solver configuration will reproduce the reported results.
