# Scenario Selection for Long-Term Event–Loss Ensembles

This repository contains the full implementation of an optimization-based framework for generating and reducing long-term event–loss scenario ensembles. All code, documentation, ensemble generation, scenario selection, and figure generation are contained in a single Jupyter notebook for transparency and reproducibility.

The repository supports the analyses and figures presented in the associated manuscript.

## Repository Contents

```text
├── scenario_selection_gurobi.ipynb   # Full workflow including ensemble generation and optimization
├── Data/
│   ├── Inputs/                       # Input data used by the notebook
│   └── Outputs/                      # Generated ensembles and optimization outputs
├── Figures/                          # Figures generated for the manuscript
└── README.md
````

## Overview

The notebook implements an optimization-based scenario selection framework designed to reduce large ensembles of long-term event–loss timelines while preserving key statistical and temporal properties. The reduced scenario sets are evaluated against the full ensemble using diagnostics related to event occurrence, hazard intensity, and loss behavior.

All preprocessing, ensemble generation, optimization, evaluation, and figure generation steps are executed within the same notebook to ensure full traceability of results.

## Methods Summary

The analysis proceeds in four main stages.

1. Generate a full ensemble of long-term event–loss timelines
2. Formulate and solve a mixed-integer optimization problem for scenario selection using Gurobi
3. Evaluate the statistical fidelity of reduced scenario sets relative to the full ensemble
4. Generate figures and summary statistics used in the manuscript

The optimization selects a subset of scenarios and assigns unequal weights to best match reference statistics computed from the full ensemble.

## Full Ensemble Generation

The analysis requires a full ensemble of long-term event–loss timelines. The notebook supports two workflows.

1. Load a pre-generated full ensemble from `Data/Inputs/` if it is already available
2. Generate the full ensemble within the notebook and save it to `Data/Outputs/`

When the notebook is run from top to bottom in a clean repository, it will first generate the full ensemble and then proceed to scenario selection, evaluation, and figure generation. Generated ensembles are saved to disk and reused in subsequent runs to reduce computational cost.

## Main Notebook

### scenario_selection_gurobi.ipynb

This notebook contains:

• Full ensemble generation
• Data loading and preprocessing
• Optimization model formulation and solution using Gurobi
• Sensitivity analyses across reduced set sizes and random seeds
• All figure generation used in the manuscript
• Inline documentation explaining each step of the workflow

Running the notebook sequentially reproduces all results presented in the manuscript.

## Data

### Input Data

All required input data are located in the `Data/Inputs/` directory. These datasets are read directly by the notebook.

### Output Data

## Figures

The `Figures/` directory contains all figures generated by the notebook. These figures correspond directly to those shown in the manuscript.

Figures are generated programmatically within the notebook and saved to this directory to ensure consistency and reproducibility.

## Running the Code

### Requirements

The analysis was developed and tested using Python 3.x.
The optimization relies on Gurobi and requires a valid Gurobi license.

### Execution

Open and run the notebook:

```bash
jupyter notebook scenario_selection_gurobi.ipynb
```

Execute all cells sequentially to reproduce the full analysis, ensembles, and figures.

## Reproducibility

All random seeds used in the analysis are explicitly set within the notebook. Running the notebook with the same inputs and solver configuration will reproduce the reported results.

## Data Availability

All data and code used in this study are provided in this repository. The analysis was implemented entirely within the `scenario_selection_gurobi.ipynb` notebook.
